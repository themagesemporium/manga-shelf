# Mage Lookup + Mage Tools (Google Apps Script)

Backup copy of the code that runs in the Mage Lookup Google Sheet (Extensions > Apps Script).
No keys live here: CLIENT_ID / CLIENT_SECRET / GBOOKS_KEY are in Script properties only.

- Code.gs: ISBN look-up, Shopify connection, draft maker, web app entry (doGet).
- Scanner.html: Mage Scanner (web app URL).
- Tools.gs + Tools.html: Mage Tools (web app URL + ?page=tools): Order check, Scan to stock, Price-check list.
